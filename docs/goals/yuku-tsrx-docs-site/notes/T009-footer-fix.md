## Changes

### B1: the unverifiable license claim is gone

- `docs/site.config.mjs`: `footer.copyright` was `'MIT Licensed'`, copied from
  oxc-tsrx. It is now `''`, with a comment saying why: no license has been
  chosen for this repository, so the footer states none, and the string stays
  empty until a LICENSE file exists. Choosing a license is the owner's call and
  this task does not make it.
- `docs/build.mjs:836`: the `<p class="footer-badge">` element is now emitted
  only when `config.footer.copyright` is non-empty, so an empty string produces
  no element rather than an empty paragraph.

The rendered home footer is now GitHub link plus disclaimer:

```html
<footer class="home-footer">
  <p class="footer-links"><a href="https://github.com/compiled-run/yuku-tsrx" ...>GitHub...</a></p>
  <p class="footer-disclaimer">An independent project, not affiliated with the Yuku team.</p>
</footer>
```

### C2: the encoder/decoder banner sentence

`docs/architecture/yuku-dialect.md:143` claimed all three generated files open
with `generated by tools/estree/decoder.zig`. Verified against the package:

- `npm/yuku-tsrx/decode.js:1` = `// generated by tools/estree/decoder.zig, do not edit`
- `npm/yuku-tsrx/encode.js:1` = `// generated by tools/estree/encoder.zig, do not edit`

The sentence now names `decode.js` and `decode-analyzer.js` for the decoder
banner and `encode.js` for the encoder banner, and says all three carry the
`DIALECT_RECORDS` table.

### C1: the codegen quotes limitation

`docs/guide/codegen.md` gained one paragraph after the `GenerateOptions` table.
It states as a current limitation that `quotes: "shortest"` and `minify: true`
are declared in `npm/yuku-tsrx/index.d.ts` but fail at the native boundary with
`invalid enum value for codegen.Quotes: 'shortest'`, because
`src/dialect/codegen.zig:611` is `pub const Quotes = enum { preserve, double, single };`,
and it points readers at `preserve` / `double` / `single` and at
`minify: { whitespace: true, syntax: true }`. It promises no fix; the product
bug is out of this goal's scope.

### C3: hero panel trailing line

`docs/demo-sources.mjs`: `heroCode` ended with a newline after the closing `}`,
which rendered an empty line 17 in the home code panel. The template literal now
closes right after `}`. The built panel has 16 `<span class="line">` elements and
the last one is `}`, matching oxc-tsrx.
